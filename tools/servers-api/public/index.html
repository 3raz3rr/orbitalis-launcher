Space Station

Как это устроено

Игра начинается с лаунчера, не с сайта BYOND.

Игроку

Один файл. Лаунчер сам ставит клиент, подтягивает ресурсы и сажает на выбранный сервер.

Владельцу

Вход через Discord, карточка сервера и orbitalis_bridge.dm в билд. Оттуда идут онлайн и наши входы.

Сети

Orbitalis остаётся домом. Остальные миры живут в той же колонке справа, каждый со своим фоном.
